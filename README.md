# Jogo de Adivinhação em Python

Jogo de terminal em que o jogador tenta descobrir um número secreto sorteado entre 1 e 100.
A cada chute, o programa indica se o número secreto é maior ou menor.
No final, mostra o número de tentativas e todos os chutes feitos.

## Como rodar

1. Tenha o Python 3 instalado
2. No terminal, execute:

    python jogo-adivinhacao-python.py

## O que pratiquei

- Laços de repetição (`while`)
- Estruturas condicionais (`if` / `elif`)
- Listas (`append`, `len`)
- Entrada do usuário com `input()` e conversão com `int()`
- Módulo `random` para sortear números
- f-strings para formatar mensagens
